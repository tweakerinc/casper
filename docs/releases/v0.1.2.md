# Casper v0.1.2

**Product:** Casper · **Base:** CrossPoint Reader 1.5 · **Devices:** Xteink X3 & X4 (single dual binary)

Firmware download: `Casper-v0.1.2.bin` (or the matching release asset for your build).

---

## Highlights

Casper v0.1.2 is a **reading-first UI release** on the CrossPoint 1.5 engine: clearer home and settings chrome, customizable status bars, a dedicated **Stats** settings folder, optional **stat tracking off** for privacy-minded readers, better cover thumbs, and a full set of **home / reader shortcuts**.

---

## What’s new

### Home & themes

- **Stats** (Dashboard) home — cover, book metrics, lifetime stats, streak
- **Bare** home — minimal chrome with text-only footer
- Theme picker limited to **Stats** and **Bare** (other skins still load if already chosen, but aren’t re-selectable)
- Black selection chips (lists, option popups, book menus) with **vertically centered** labels
- Header titles (**Settings**, **Manage Fonts**, etc.) centered between the **status chrome** (clock / battery) and the rule above the tabs

### Status bars (two independent systems)

| Where | What |
|--------|------|
| **Settings → Display → Status Bar** | System top chrome for home, settings, and menus |
| **Customize Reader UI** | Six-slot reader chrome (upper / lower × left / middle / right) |

**System Status Bar**

- Per-slot content: **Hide · Battery · Clock** (each exclusive)
- Nested **Battery Display** under a Battery slot: **Icon · Percent · Icon + Percent** (default **Icon + Percent**)
- Nested clock options when Clock is placed (format, UTC offset, sync)
- Live preview at the top of the screen
- Stats theme defaults: battery left, clock right; Bare defaults: all hide

**Customize Reader UI**

- Six exclusive slots for battery, clock, page counters, progress %, time left, titles, XTC placement, etc.
- Same nested **Battery Display** modes as system chrome (stored separately so the reader can stay minimal)
- Progress bar mode + thickness
- Live preview with a reserved “Preview” band (chrome lifted clear of button hints)

### Battery display modes

When Battery is assigned to a slot (system or reader):

| Mode | Shows |
|------|--------|
| **Icon** | Battery icon only |
| **Percent** | `NN%` text only |
| **Icon + Percent** | Icon and percent (default) |

System and reader modes are **independent**.

### Manage Fonts (Text Settings)

- Tabs: **Font · Size · Layout · Style**
- Live reader-accurate preview
- Layout roughly **50/50** list vs preview so more fonts fit on screen before scrolling
- **Download Fonts** as a row in the Font list (not a fifth tab)
- Built-ins slimmed to **Source Serif 4** (default UI / reader) and **Bitter**
- Side buttons switch font tabs; front buttons move the list

### Settings navigation (tabbed screens)

Applies to **Settings**, **Manage Fonts**, and similar tabbed menus:

| Control | Action |
|---------|--------|
| **Front Up / Down** | Move within the **current** tab’s list (wraps to that tab’s label, not the next category) |
| **Side buttons** | **Always** previous / next tab (whether focus is on the tab bar or a list row) |
| **Confirm** on tab bar | Advances to the next tab and enters its first list row |
| **Touch** (future X4 Pro) | Tap tabs / rows when a touch panel is present |

### Stats folder & privacy

**Settings → System → Stats** (directly under **Wi‑Fi**):

| Item | When shown |
|------|------------|
| **Enable Stat Tracking** | Always (default **On**) |
| **Auto Backup Stats** | Tracking on + X3 (RTC) |
| **Backup Stats** | Tracking on (bottom of the list) |

Removed from the main System list so they aren’t duplicated: Backup Stats, Auto Backup, and the old “Disable Stat Tracking” toggle.

When **Enable Stat Tracking** is **Off**:

- No new reading time / session stats are recorded
- **Reading Stats** is removed from home menu, long-press book menus, and long-press Confirm if set to Reading Stats
- Also hidden: **Reset Reading Pace**, **Delete Book Stats**, **Mark Finished / Unfinished**
- Existing on-disk stats files are **not** deleted

### Cover thumbnails

- Brighter 1-bit cover pipeline (**c5**) for home thumbs
- Stronger midtone handling for metallic / gold title type without crushing the whole cover dark
- Thumbnails regenerate under a new cache name after update

### Other polish

- Option popups (Cancel / Confirm, enum pickers) use **black** selection chips, not light gray
- Long-press **Library → Recent Books** waits for full button release so the first book is not opened by accident
- Clean boot / System version string: **`v0.1.2`** (no long `dev-branch-sha` stamp on Casper builds)
- Dual **X3 + X4** binary; X3 / X4 remain button-first (no touch); X4 Pro touch is reserved for a later device profile

## Home shortcuts

Front buttons map 1:1 to the footer labels. Side buttons are unused for root home navigation (page turn in the reader).

### Stats home (Dashboard)

| Front button (left → right) | Short press | Long press (~0.5s) |
|-----------------------------|-------------|---------------------|
| **Menu** (Back) | Open home popup menu | — |
| **Browse** (Confirm) | Open Library (file browser) | — |
| **Settings** (Left) | Open Settings | — |
| **Read** (Right) | Continue current book | Book action menu |

**Home popup menu (Menu)** typically includes:

- Recent Books  
- Reading Stats *(if tracking enabled and a current book exists)*  
- OPDS Browser *(if OPDS servers are configured)*  
- File Transfer  
- Settings *(Bare also lists Settings in this menu; Stats keeps Settings on its own key)*  

### Bare home

Footer order: **Menu · Library · Synopsis · Read**

| Front button | Short press | Long press (~0.5s) |
|--------------|-------------|---------------------|
| **Menu** (Back) | Open popup (Recent Books, File Transfer, … + Settings) | **Settings** |
| **Library** (Confirm) | Open file browser | **Recent Books** (waits for release before any select) |
| **Synopsis** (Left) | Current book description | — |
| **Read** (Right) | Continue reading | Book action menu |

## Book long-press menus

Available from **long-press Read** on home, **long-press Confirm** on a Recent Books row, or equivalent book action entry points.

Typical items (stats-related rows only when **Enable Stat Tracking** is On):

| Action | Notes |
|--------|--------|
| Open | Open / resume the book |
| Synopsis | Book description |
| Reading Stats | Per-book stats *(tracking on)* |
| Reset Reading Pace | Clears pace samples *(tracking on)* |
| Remove from Recents | When opened from recents |
| Mark Finished / Unfinished | *(tracking on)* |
| Delete | Delete file from SD |
| Delete Book Stats | *(tracking on)* |
| Delete Cache | Clear layout / reading cache for the book |

## Reader shortcuts

### Page turn & power (Casper defaults)

| Control | Default |
|---------|---------|
| Side buttons | Page previous / next (layout in Settings → Controls) |
| Short power | **Sleep** |
| Long power (hold past long-press threshold) | **Force full refresh** |
| Long-press Confirm (reader) | **Dictionary** (changeable under Settings → Controls → Long-Press Menu) |

**Long-Press Menu** options include: KOReader Sync, Disabled, Bookmark, Dictionary, Sleep, Force Refresh, Browse Files, Screenshot, Footnotes, File Transfer, Reading Stats *(honored only if tracking is enabled)*.

### Dictionary (long-press Confirm → Dictionary)

- Offline StarDict packs under `/dictionaries`
- Multi-pack select in Settings → Reader → Dictionary  
- Multi-word selection: long-press Select to arm a range, move with Left/Right, short Select to look up

### Reader hamburger menu (tabs)

| Tab | Contents (summary) |
|-----|---------------------|
| **Main** | Dictionary, Chapter, Footnotes (if any), Go to %, Auto page turn, Orientation, Mark Finished *(if tracking on)*, Go Home |
| **Bookmarks** | Sync progress, Add/Remove bookmark, View bookmarks, Clippings, Screenshot, Display QR |
| **Settings** | Reading Stats / Reset Pace / Delete Stats *(if tracking on)*, Delete Cache, Delete Bookmarks |

Navigation: front Up/Down move the list; side buttons switch tabs; Confirm activates the row (or next tab when the tab bar is focused).

### Customize Reader UI

Open from **Settings → Reader → Customize Reader UI** (or the reader path that launches the six-slot editor). Assign chrome per corner/slot and nest **Battery Display** under Battery.

## Install notes

1. Flash `Casper-v0.1.2.bin` with your usual SD / web / esptool flow.  
2. After first boot, open a book once so **cover thumbs** regenerate under the new pipeline.  
3. If status bar or battery modes look wrong, open **Display → Status Bar** and **Customize Reader UI** once — settings resave cleanly after the battery-display migration.  
4. Privacy: **System → Stats → Enable Stat Tracking → Off** to stop all new tracking and hide stats UI.
