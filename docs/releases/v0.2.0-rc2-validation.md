## Scope and remaining limitations

This candidate implements full-source sliding-window ingestion, SD-backed chapter/page-map working sets, independently owned preparation, previous/next/rest readiness scheduling, persisted count/checkpoint data and content-anchor navigation. It does not intentionally redesign themes, menus, book styling or the X3/X4 statistics policy.

A complete chapter representation is still prepared before its first page is published. ZIP extraction remains entry-scoped with cancellation checks, and a cold chapter ending still requires forward pagination from the last known checkpoint. No zero-wait cold-open claim, measured on-device speed gain, battery/ghosting result or crash-free guarantee is made. Full CSS/ZIP64 support and the separate networking/security/waveform audit are not included.

See `v0.2.0-rc2-test.md` for storage bounds and device acceptance. Back up the SD card and keep known-working firmware; use the SD updater initially. The chapter 1 -> 15 -> Back into 14 sequence, sleep/resume and font/orientation changes require real-device testing. No stable/main merge, tag or production release has been made. This validation-note update changes documentation only; the downloadable binary remains the exact `59f94a7` build.
