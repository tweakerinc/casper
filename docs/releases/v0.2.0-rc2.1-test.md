# Casper v0.2.0-rc2.1 — targeted RC2 recovery candidate

For the combined ESP32-C3 X3/X4 build. Not X4 Pro. Not a stable release.

## Changes relative to RC2

- Make `HalFile::close()` safe on default, moved-from and already-closed handles. Real open-file close failures remain failures. Read/write/seek assertions remain enabled. This addresses the supplied X3 panic: `HalStorage.cpp:268 (impl != nullptr)` on entry to Rivulet.
- Stop the repeated Home cover-generation pass when a failure produced no new usable thumbnail. Let the missing-cover screen settle when no automatic retry remains. No book, user setting, statistic or image file is deliberately erased by this fix.
- Add tests compiling actual `lib/hal/HalStorage.cpp`, with mock SdFat/RTOS below it, including the book-count index and paged record store. The earlier permissive HalStorage mock did not enforce the device cleanup behavior.

Rivulet's RC2 indexing, page-map format and styling rules are retained. No theme geometry, waveform constant, statistic policy, font selection, or layout rule is intentionally changed.

## Limits

This is a reboot/retry-stall hotfix, not a claim that every reset is fixed. It does not repair the specific progressive JPEG that failed in the supplied log. That cover can remain missing, but the same failing generation should no longer repeat eight times during the same Home visit. Re-entering Home can try once again. No physical-device performance, artwork, SD power-loss or stability result is asserted.

## Installation

Back up the SD card and retain known-working firmware. Copy the `.bin` to the SD card and choose it in Settings -> System -> SD Firmware Update. If Home is unusable, the existing Up + Power recovery entry opens the SD updater. Use stable power during flashing. Do not flash the `.elf`; retain it for crash decoding. Do not factory-reset or clear the SD card as a prerequisite.

First test opening a book, then return to Bare Home. Record the new version/build ID if a failure occurs. Additional fixes will be based on the new logs rather than repeatedly reflashing the known-bad RC2 image.
