## Scope and limits

Repairs ordinary div block boundaries and linked/embedded CSS loading, preserves paragraph/style whitespace, extends sparse navigation with real spine sections/source-derived labels, repairs FAT-backed progressive JPEG storage, defers optional ready-page writes, guards background preparation with inflater headroom and a quiet period, and services the watchdog during ZIP output chunks. The RC2.1 file-close fix remains. Theme geometry, menu appearance, user-selected fonts and X3/X4 statistics policy are not deliberately redesigned.

The loader tests use mocked font metrics, ZIP transport and image geometry. The cover tests compile the production converter, jpgd, pinned JPEGDEC and storage adapter, with mocked SdFat/RTOS below the adapter. Sanitizers run on a host, not the reader; JPEGDEC's intentional unaligned host accesses have their alignment sanitizer disabled while other checks remain. Real heap fragmentation, SD latency, physical refresh/ghosting, final glyph placement and battery behavior are not certified. The field watchdog report has no captured stack, so its exact instruction is not established.

CSS support is a bounded subset, not a browser engine. Cold chapter conversion and first cover generation still take work. Actual device speed must be measured. See `v0.2.0-rc3-test.md` for remaining layout and navigation limitations.

## Installation and acceptance

Back up the SD card and retain a known-working firmware; install the BIN with the SD Firmware Update function using stable power. Do not flash the ELF or factory-reset. Old derived IR/page caches rebuild automatically; user progress/bookmarks/statistics are not intentionally erased. Because restored paragraph boundaries alter text-derived positions, verify your last reading location on the first opening.

Test the supplied EPUB's recap, interlude and numbered chapter headings, word spacing and paragraph separation, chapter selection/jump/backward ending, Bare and sleep covers, rapid turns, and sleep/font/orientation resume. Include build `e5acda0`, device and logs with any failure. No main merge, stable tag or production release was created.
