# Casper v0.2.0-rc4 recovery candidate

Not the completed firmware overhaul. No stability or device-speed certification.
Candidate branch only; no main merge or stable tag. Based on RC3 e5acda0 and
retains its UI geometry, stylesheet/paragraph fixes, SDK pin, font selections,
and intentional X3/X4 statistics policy. Target: ESP32-C3 X3/X4, not X4 Pro.

## Recovery changes

- Recognize a source-verified chapter-start anchor across known IR upgrades;
  match 16-byte context across new contiguous formatting runs at the same source
  text offset. Do not guess pages for ambiguous/mismatching anchors. Resolution
  does not erase the original saved record. A rejection gets a specific log.
- Pack materialized progressive-JPEG coefficient rows instead of writing unused
  gaps; separate small interleaved DC rows from AC row storage. Pixels unchanged.
- Optional Home cover preparation checks raw button input (without consuming its
  edges) during ZIP output, JPEG input/spill I/O, and output rows. Cancellation
  removes partial output and pauses retries for 8 seconds. It is cooperative
  cancellation, not a new asynchronous worker or guaranteed input deadline.
- When Home needs a JPEG thumbnail and cover sleep is selected, prepare the
  correctly sized sleep BMP during the same progressive decode. Secondary scaling
  uses source pixels, NOT an enlarged or redithered thumbnail. Respect Fit/Crop.
- EPUB sleep consumes a completed cover cache without loading metadata, extracting
  the ZIP, or decoding a missing image. With no ready image it uses the existing
  configured no-cover fallback instead of holding the power request for decoding.
- Paired JPEG artifacts are staged before publication; cancellation cannot publish
  a partial thumbnail. Other image/format handlers retain their current behavior.

## Tests

Local ASan/UBSan reader suite: 3,583 assertions passed. Actual storage-adapter
lifecycle: 62 checks; cover-retry policy: 20 checks. Production-component suite
passes against synthetic fixtures and the private failing EPUB: all 126 spine
sections retain cold/warm conversion and first-page-cache consistency. Original
cover: 1,407,000 grayscale source pixels match the resident reference. Packed
scratch store: 1,088 writes / 8,283,128 bytes vs RC3 8,023 / 11,833,088.

Paired Bare/sleep BMP output matches separate native-size conversions byte for
byte. Cancellation is injected before decode, during decode, and near final
output; a following retry still matches. Tests compile actual converter, decoder,
loader, parser and storage adapter with mocked lower hardware/filesystem layers.
These checks do not measure physical SD latency, final glyph placement, touch
handling, panel ghosting, sleep current, or end-to-end device responsiveness.

## Known limitations

Cold covers still require work when Home is idle. PNG decode and custom-image,
TXT/XTC sleep paths are not made interruptible by this patch. A warm thumbnail
without a matching sleep cache does not independently schedule a sleep-cover job;
that wider background-asset coordinator remains to implement. Fit may have side
margins; the existing Crop option changes composition intentionally. No default
crop or quality reduction is forced. Non-start resume anchors whose normalized
text offsets changed beyond the exact context case can still require recovery.
Full streaming first-page opening, scheduler deadlines, and the comprehensive
responsiveness overhaul remain unfinished.

## Installation and acceptance

Back up SD including hidden folders; keep known-working firmware. Install the BIN
through SD Firmware Update with stable power; never flash the ELF. Do not factory
reset or clear the book cache to fix resume. There is no IR-format bump here.

Test: reopen the saved chapter from RC2/RC3, turn pages and navigate backward;
press a navigation/power button during a cold cover preparation; sleep with a
warm cover and with no cover cache; confirm Fit/Crop and book typography. Capture
version/build and logs. A successful compile is required before distributing BIN.
