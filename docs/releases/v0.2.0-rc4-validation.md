## User-visible scope

Targeted saved-position migration handles verified chapter starts across known parser versions and matching context split into new formatting runs. It does not guess arbitrary saved positions. Progressive-cover scratch storage uses fewer writes without changing source pixels. Home can prepare thumbnail and sleep artifacts in one progressive decode and cooperatively cancel JPEG work on raw button input. EPUB sleep consumes ready cover data instead of starting a cold decode. RC3's stylesheet/block fixes, theme geometry, selected fonts and intentional X3/X4 statistics policy remain.

When no ready sleep image exists, the existing no-cover fallback is used. A warm thumbnail without a matching sleep cache does not independently schedule a sleep-image job yet. PNG decode and non-EPUB sleep handlers are unchanged. First cover preparation still takes work; no guaranteed cancellation deadline is established. Non-start resume anchors with shifted normalized offsets can still require recovery. The broader UI scheduler, first-page streaming and full backend overhaul remain unfinished.

Back up SD and retain known-working firmware. Install the BIN through SD Firmware Update with stable power; never flash the ELF. No factory reset or cache wipe is required; the IR format was not bumped. First test the saved chapter, normal/backward turns, cancellation during cold cover work, and sleep with warm/missing cover data. Existing Fit/Crop choice is unchanged. No main merge, stable tag or production release was made.
