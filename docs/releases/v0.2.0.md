# Casper v0.2.0

**Product:** Casper  
**Based on:** CrossPoint Reader 1.5 & CrossInk  
**Devices:** Xteink X3 & X4 (one binary for both)

**Firmware:** `dist/Casper-v0.2.0.0000.bin` (tag `v0.2.0` when you publish GitHub)

This is a field build. Ship it, then wait for reader feedback before the next train.

---

## Highlights

v0.1.9 was the reading-feel release. v0.2.0 is the “it stays readable, dark, and where you left it” release on top of that.

**What’s new at a glance:**
- **Chapters stay readable** — existing CrossPoint / CrossInk chapter caches load; sitting open converts a prefix instead of failing as **Chapter not readable**
- **Dark Mode** inverts the whole UI and stays inverted through menus, Bare greys, Opening, and first wake
- **Home covers** paint from whatever thumb is already on SD. Back never re-decodes JPEG. No 280→560 “tiny then bigger”
- **Sleep is last-frame** — Factory Sleep Screen is Quick Resume; power-button sleep is the only power-button action
- **Fonts over WiFi work** — catalog is the live `crossink-fonts` bucket (v0.1.9 pointed at a missing `legacy-fonts` bucket)
- **WiFi firmware update can finish** — no full e-ink refresh during the GitHub TLS download; retries; framebuffer loan
- **Hail Mary** chapter titles and drop caps land on the same page
- **X4 Home** chrome matches X3 (labels, footer band, Penumbra title + author)

## What’s New

### Chapters stay readable

v0.1.9 could delete a still-good CrossPoint / CrossInk chapter cache and then run out of RAM converting it again. v0.2.0:

- Loads chapter IR **v19–v26**. A cache that is merely an older CrossPoint format is **not** treated as corrupt.
- Sitting open **must** produce IR when the EPUB has HTML: framebuffer loan covers cache + convert, HTML is converted in a prefix, extra convert retry on sitting loads.
- Sibling `sN_m{0,1,2}.rvir` files are used. A partial convert does **not** wipe a good `.rvir`.
- Fail string is still **Chapter not readable** — it should fire far less often.

**Try:** books that used to fail on first open of a chapter, and books already laid out on a CrossPoint / CrossInk card.

### Hail Mary / drop caps / clippings

- Chapter titles and drop caps stay on the **same page** (map format 2).
- Clippings no longer abort the page paint.
- X4 clippings **underline** instead of dither boxes.
- **DCC `[ 70 ]` still does not arm** a drop cap. That is unchanged; do not expect Project Hail Mary’s numeric chapter markers to grow a cap.

### Dark Mode

- **Settings → Display → Dark Mode** inverts the **whole UI** (Home, menus, settings). Nested **Reader Only** is still there; the reader menu does **not** force reader-only.
- Bare cover greys and AA stay inverted. Covers themselves are pre-inverted with `invertRect` so they are not a second negative.
- Opening HALF, first QR wake, and menu Up/Down no longer flash a black (un-inverted) frame.
- Loading text stays readable on a dark plate.

### Home covers

- If **any** cached thumb exists (560 / 280 / 168), Back / Home **blits it**. JPEG decode runs only when nothing is on SD.
- There is **no** preview-then-hero upgrade (280 painted small, then 560). That 280→560 “tiny then bigger” path is gone on purpose.
- Bare covers paint without waiting a minute for 560 greys.

### Sleep / wake

- Sleep is **last-frame** (INX-style): the page you were on is the sleep plate. Factory Sleep Screen is **Quick Resume**.
- Power-button action is **Sleep only**.
- **SLEEPING** / **BOOTING** corner cues while sleep or wake works.
- White Quick Resume wake flash is skipped. GPIO13 stays held off through C3 deep sleep so X4 does not bounce.
- X4 **Reset → Power** after a flash still takes the splash / Home path (unplug/replug alone is often not enough).

### Fonts over WiFi

v0.1.9’s Manage Fonts download pointed at `legacy-fonts` (S3 `NoSuchBucket`, HTTP 404). v0.2.0 uses the live catalog:

`http://crossink-fonts.s3.us-east-1.amazonaws.com/sd-fonts-m1-b4/fonts.json`

**Try:** Settings → Manage Fonts → download a family over WiFi.

### WiFi firmware update

- No full e-ink paint during the ~5.4 MB GitHub TLS download (that paint was aborting the transfer).
- Framebuffer loan + **3 retries**.
- A GitHub release with no matching `.bin` reports **No update available**, not **Update failed**.

**From a v0.1.9 device, Check for updates only offers v0.2.0 after you publish GitHub tag `v0.2.0`.** The dist filename is `Casper-v0.2.0.0000.bin`. You can also attach `Casper-v0.2.0.bin` (same bytes) on the GitHub release; both names are valid OTA assets.

A device already on `v0.2.0` against tag `v0.2.0` correctly reports no update.

### Place, taps, Flip Orientation

- **Flip Orientation** keeps the page you were on.
- Chapter `[1]` first-letter bold is the letter, not only `[`.
- First tap after open turns the page. Page-turn taps are not dropped on the idle poll / 10 MHz idle path.
- Back leaving a book does not also page-turn.
- Next-chapter page 1 can prefetch onto SD for instant hops. Idle convert / skip-ahead will not run on a failed chapter.

### Music notes

Builtin faces that omit music-note glyphs still render them (fallback from a face that has them).

### X4 Home (parity with X3)

- Footer band and label sit like X3 (20 px gap, not a 56 px hole; 34 px Bare footer).
- Penumbra shows title + author; Recents uses the same G as the hairline.
- UI glyphs are dense (Sourcerer chrome is not whispy).
- One side press per under-panel page. Battery Warning paints on Bare / Penumbra.
- Dictionary highlight is centered on glyph ink; Lookup title inset matches.

### Logging / cache hygiene

- **Enable Logging** writes captures onto the SD card.
- Deleted-book stats stay in the cache `.trash` folder. **Deleted** flashes in the corner after a cache wipe.

### Linux USB flasher

Desktop Linux can flash X3 / X4 / X4 Pro over USB (pkexec retry on serial `EACCES`). The web flasher remains the recommended path for most people.

## How to Install

1. Flash `Casper-v0.2.0.0000.bin` (or `Casper-v0.2.0.bin` if you copy the same bytes onto the GitHub release).
2. **X4:** after flashing, use **Reset → Power** so the new image actually boots (unplug/replug alone is often not enough).
3. Book cache layout is unchanged: `/.crosspoint/epub_<hash>/`. There is no SD migrate for this release.

### CrossPoint web flasher (recommended)

1. Download **Casper-v0.2.0.0000.bin** from the release (or the matching `Casper-v0.2.0.bin`).
2. Connect your **X3 or X4** via USB-C and wake/unlock it.
3. Open [https://crosspointreader.com/#flash-tools](https://crosspointreader.com/#flash-tools) (Chrome / Edge / Firefox on desktop).
4. Select **Xteink X3** or **Xteink X4**.
5. Click **Custom .bin** and choose the file.
6. Flash, then reset/wake the device if prompted.

### SD firmware update

Copy `Casper-v0.2.0.0000.bin` (or `Casper-v0.2.0.bin`) to the root of the SD card → **Settings → System → SD Firmware Update**.

### WiFi OTA (after the GitHub tag exists)

On a **v0.1.9** device: **Settings → System → Check for updates**. The device only sees this build once tag `v0.2.0` is published with a `Casper-v*.bin` asset.

## Not in v0.2.0 (deferred)

- Whole-book Home indexing (still disabled; it froze the UI).
- Font Darkness / ink-weight sliders (AA on/off + Mild raster are the controls).
- Windowed greyscale in the display HAL (clock AA is still a full-frame grey pass).
- PNG decoder lifetime: the decoder can still sit warm at ~50 KB. Next efficiency pass, not this ship.
- DCC `[ 70 ]` drop-cap arming.
- `book_<id>/package` cache rekey (abandoned; CrossPoint / CrossInk folders stay).
